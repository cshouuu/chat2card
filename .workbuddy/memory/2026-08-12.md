## Windows 环境踩坑记录(重要)

1. **npm install 后台+管道模式会卡死**:`npm install 2>&1 | tail -n` 在后台运行时无输出无进展(0 文件,10 分钟)。解决:重定向到日志文件 `> /tmp/x.log 2>&1`,前台或后台跑都正常。
2. **官方 registry 超慢/卡住**:用 `--registry=https://registry.npmmirror.com` 单次参数(不污染全局配置)。
3. **puppeteer-core 无头截图**:
   - 用系统 Chrome(`C:/Program Files/Google/Chrome/Application/chrome.exe`),不要 Edge(x86)。
   - 每次用**新的临时 user-data-dir**(`os.tmpdir()/c2c-profile-{ts}`),避免残留锁冲突;本环境 rm/Remove-Item 被安全策略拦截(safe-delete 走回收站失败),目录删不掉就换新目录绕开。
   - CSS `zoom` 会干扰 element.screenshot 的 boundingRect(截图框选错乱/截断),截图前需把 zoom 重置为 1。
4. **PNG 尺寸验证**:用 Python struct 解析 PNG 头(偏移 16 起 4+4 字节为宽高),避免 Add-Type/图片查看。
